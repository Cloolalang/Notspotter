Antenna input power spread between antennas

    Each bar is the power at that antenna input: source power minus passive loss. It is not radiated power. A longer bar is a stronger signal. The scale is 10 dB under the strongest level, and every chart uses that same scale. Cable figures show source 1, then source 2 while it is on.

    Branch output

    Output is the linear sum of every antenna input, written in dBm. Branch loss is the source power minus that output.

    Optimise sets each coupler to 6, 7, 8, 10, 13, 15 or 20 dB from the coupled cable type and length, so the antenna inputs stay level. A longer or lossier cable gets a tighter coupler. A shorter or lower-loss cable gets a looser one. Splitter legs, or the end coupler’s two cables, count too. The end can be a splitter or a coupler. The coupler starts at 5 dB, coupled port then through port, and optimise can change it. All bands follows the worse frequency. A or B follows one source.

    Best-quality straight N connectors were checked and left out of the loss figures. A mated pair is about 0.05 dB, about 0.2 dB at antenna input 1 and 0.5 dB on the splitter legs. Point-of-failure list: every connection, numbered cable, and passive.
